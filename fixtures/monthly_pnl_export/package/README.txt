Synthetic monthly P&L reviewer export package
================================================

This package is generated from fictional fixture data only. Account aliases are not real accounts.
It contains no real export, correction, upload, queue change, credential or production accounting data.

Use rows.csv for immutable original rows, reviewer_corrections.csv for manual review amendments,
original_vs_amended.csv for row-level before/after values, and reversible_replacements.json for the
reverse-and-replace adjustments needed to reproduce or undo each correction. Evidence references are
relative paths inside this package. All amounts are integer cents.
